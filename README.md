# AI Agricultural Assistant: FARM-NEXA

Welcome to **FARM-NEXA**, an innovative **AI Agricultural Assistant**! 🌱 This application is designed to provide valuable support and guidance to farmers globally. The assistant helps with a wide range of farming-related queries and focuses on improving productivity, promoting sustainable agricultural practices, and addressing common challenges faced by farmers.

## Overview

**FARM-NEXA** is an AI-powered application that can assist with:
- Identifying and diagnosing **crop diseases**.
- Providing advice on **weed control**.
- Offering guidance on **plantation** and general farming practices.
- Answering **farming-related queries** in multiple languages.

The goal is to support farmers by providing them with accurate, timely, and practical advice to help them optimize farming practices and boost productivity.

### Multilingual Support
The application provides support in both **English** and **Hindi**, ensuring accessibility for a wide range of users.

## Key Features

- **Text Interaction**: Ask questions about farming via text input and receive answers instantly.
- **Audio Interaction**: Upload an audio question, and the assistant will transcribe and respond to it, making it easy for farmers who may prefer speaking over typing.

## **FARM-NEXA CAN ALSO BE INTEGRATED INTO ANY COUNTRY'S GOVERNMENT OR PRIVATE WEBSITE RELATED TO AGRICULTURE, FARMING, OR ENVIRONMENTAL SUSTAINABILITY. THIS MAKES IT A VERSATILE SOLUTION FOR ENHANCING AGRICULTURAL ADVISORY SERVICES AT A NATIONAL OR GLOBAL SCALE.**

## Technology Stack

The app utilizes the following technologies:
- **Streamlit**: A framework for building interactive web apps.
- **OpenAI API**: Used to power the AI assistant for generating responses to farming-related questions.
- **MoviePy**: A Python library used to handle and transcribe audio files.
